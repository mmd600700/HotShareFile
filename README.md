# 🔥 HotShareFile

**Easily share files between your Android phone and any device (Android, iOS, laptop, etc.) over a hotspot, with two-way file transfer.**

---

## ✨ Features

- 📤 **Two-Way Transfer:** Send and receive files seamlessly. Users on the web interface can also upload files.
- 🔗 **QR Code Toggle:** Tap on the displayed URL (`http://192.168.43.1:8888`) to instantly convert it into a QR code for quick scanning.
- 🌐 **Cross-Platform:** Access the web interface from any device with a browser (Android, iOS, Windows, macOS, Linux).
- 🔒 **Private & Offline:** Direct device-to-device communication via hotspot. No internet connection or external servers are required.
- 📁 **Any File Type:** Share photos, videos, documents, APKs, and more.
- ⚡ **Simple & Fast:** No cables, Bluetooth, or additional apps needed on the receiving device.

## 🚀 Quick Start

### Prerequisites

- An Android device running **Android 5.0 (API 21) or higher**.
- The receiving device must have a web browser.

### Installation & Usage

1.  **Install the App:**
    - Download the latest APK from the [Releases](https://github.com/mmd600700/HotShareFile/releases) section.
    - Or, clone and build the project using Android Studio.

2.  **How to Use:**
    - **On the Sender Device (Android):**
        1.  Open the **HotShareFile** app.
        2.  Turn on your device's hotspot.
        3.  Tap the URL (e.g., `http://192.168.43.1:8888`) to toggle it to a QR code for easy sharing, or note the address.
        4.  To send a file, select a file using the app's interface.
    - **On the Receiver Device (Any Device with a Browser):**
        1.  Connect to the sender's hotspot via Wi-Fi.
        2.  Open a web browser and go to the address shown in the app (e.g., `http://192.168.43.1:8888`).
        3.  You can now **download** files shared by the sender, or **upload** files of your own to the sender.
